# แนวทางหน้าจอ CES Inventory โรงพยาบาลกรุงเทพขอนแก่น

หน้าจอใช้ภาษาไทยเป็นหลักและอ้างอิงภาพลักษณ์จากเว็บไซต์โรงพยาบาลกรุงเทพขอนแก่น ใช้พื้นขาวและฟ้าอ่อน หัวข้อสีน้ำเงินเข้ม และแถบแดงไล่น้ำเงินสูง 4px ด้านบนของหน้าจอ [เว็บไซต์อ้างอิง](https://www.bangkokhospital.com/th/khonkaen)

## อัตลักษณ์และตัวอักษร

- ใช้โลโก้กรุงเทพขอนแก่นต้นฉบับจากไฟล์ภายใน `ces/static/brand/bangkok-hospital-khonkaen.svg` อัตราส่วน 129 ต่อ 42 บนพื้นขาว รักษาสีและสัดส่วน กำหนดข้อความทดแทนเป็นชื่อโรงพยาบาล โลโก้ใน sidebar กว้างประมาณ 180px และหน้า Login 240px โดยปรับขนาดให้เหมาะกับมือถือ [ไฟล์โลโก้ต้นทาง](https://static.bangkokhospital.com/uploads/2025/04/bkn.svg)
- แสดงชื่อ CES Inventory แยกจากตราโรงพยาบาล และระบุชื่อโรงพยาบาลกรุงเทพขอนแก่นในหน้าหลักและหน้าเข้าสู่ระบบ
- ใช้ Sarabun น้ำหนัก 400, 600 และ 700 จากไฟล์ใน `ces/static/fonts` พร้อม `font-display: swap` และฟอนต์สำรอง Leelawadee UI, Tahoma และ sans-serif เก็บใบอนุญาต OFL ไว้กับไฟล์ฟอนต์ [แหล่งฟอนต์และใบอนุญาต](https://github.com/google/fonts/tree/main/ofl/sarabun)

## สีและองค์ประกอบร่วม

| การใช้งาน | สี |
| --- | --- |
| ปุ่มหลัก ลิงก์ และโฟกัส | `#0147A3` |
| หัวข้อและชื่อระบบ | `#002D73` |
| สีเน้นของโรงพยาบาล | `#B12028` |
| ข้อความหลัก | `#363636` |
| พื้นหน้า | `#F4F7FB` |
| พื้นการ์ดและฟอร์ม | `#FFFFFF` |

- กำหนดสีผ่าน CSS tokens ที่มีชื่อตามหน้าที่ การ์ดใช้มุมโค้ง 18px และระยะภายใน 20–24px หัวตารางฟ้าอ่อนและเส้นแบ่งบางให้เปรียบเทียบข้อมูลได้ง่าย
- สถานะสำเร็จและพร้อมใช้เป็นสีเขียว ใกล้หมดและส่งซ่อมเป็นสีเหลืองอำพัน หมดสต็อก ชำรุด และข้อผิดพลาดเป็นสีแดง ทุกสถานะมีข้อความกำกับ
- เมนูและปุ่มแสดงตามบทบาท ตรวจสิทธิ์ซ้ำที่เซิร์ฟเวอร์ ข้อความชื่อรายการ รหัส และตำแหน่งที่ยาวต้องตัดบรรทัดได้

## การใช้หน้าจอและการเข้าถึง

- ใช้ sidebar บนเดสก์ท็อปและเมนูเปิด–ปิดบนมือถือ ตรวจหน้าจอที่ความกว้าง 1440, 1024, 768 และ 390px พร้อมซูม 200% ตารางมือถือใช้รายการพร้อมป้ายชื่อข้อมูล
- ทุกช่องกรอกมีป้ายกำกับ ปุ่มที่เป็นไอคอนมีชื่อที่อ่านได้ ใช้คีย์บอร์ดเปิดเมนู ปิดด้วย Escape และทำรายการได้ โฟกัสแสดงกรอบสีน้ำเงินชัดเจน
- คงรหัสรายการ รหัสชิ้น และ Serial Number ในรูปแบบเดิม แสดงตำแหน่งเป็นเส้นทางจากห้องถึงจุดเก็บ
- ฟอร์มธุรกรรมแสดงยอด รหัสชิ้น ผู้ยืม และกำหนดคืน เมื่อทำสำเร็จให้แสดงเลขอ้างอิง เมื่อเกิดข้อผิดพลาดให้แจ้งข้อความและเก็บค่าที่แก้ไขต่อได้
- โลโก้ ฟอนต์ และ CSS ให้บริการจากแอปเพื่อรองรับเครือข่ายที่จำกัดอินเทอร์เน็ต
