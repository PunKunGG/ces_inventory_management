# แนวทางหน้าจอ CES Inventory MVP

- ใช้ภาษาไทยเป็นหลักและคงรหัสรายการ รหัสชิ้น และ Serial Number ในรูปแบบเดิม แสดงตำแหน่งเป็นเส้นทางจากห้องถึงจุดเก็บ
- เมนูและปุ่มแสดงตามบทบาท ตรวจสิทธิ์ซ้ำที่เซิร์ฟเวอร์ สีเขียวอมฟ้าใช้กับปุ่มหลัก สถานะใช้ข้อความร่วมกับสี เช่น หมดสต็อก ใกล้หมด ชำรุด และพร้อมใช้งาน
- ใช้ layout ที่ปรับกับเดสก์ท็อป แท็บเล็ต และมือถือ ฟอร์มทุกช่องมีป้ายกำกับ เน้นตำแหน่งโฟกัสเมื่อใช้งานด้วยคีย์บอร์ด และแสดงข้อความแจ้งผลที่อ่านได้
- ฟอร์มธุรกรรมแสดงข้อมูลที่ใช้ตัดสินใจ เช่น ยอดคงเหลือ รหัสชิ้น ผู้ยืม และกำหนดคืน เมื่อทำสำเร็จให้แสดงเลขอ้างอิง เมื่อเกิดข้อผิดพลาดให้ผู้ใช้แก้จากค่าที่กรอกไว้
