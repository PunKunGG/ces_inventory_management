# สถาปัตยกรรม CES Inventory MVP

กล้องมือถืออ่าน URL แล้วส่งให้เบราว์เซอร์เปิดหน้า `/` Waitress ให้บริการ Flask บน Windows Flask ตรวจเซสชันและสิทธิ์ แสดงหน้า Jinja พร้อม Bootstrap ที่เก็บในแอป และใช้ SQLite บนดิสก์ของเซิร์ฟเวอร์ ฟอร์มเขียนข้อมูลผ่าน POST พร้อม CSRF token

## โครงสร้างข้อมูล

| ตาราง | หน้าที่ |
| --- | --- |
| `users`, `user_sessions` | บัญชี รหัสผ่านที่ผ่านการ hash บทบาท สถานะ และเซสชันที่เพิกถอนได้ |
| `categories`, `locations` | หมวดหมู่และผังตำแหน่งที่เชื่อมกับตำแหน่งแม่ |
| `items`, `tool_units` | ทะเบียนรายการ ยอดอะไหล่ ยอดขั้นต่ำ รหัสเครื่องมือรายชิ้น Serial Number และสถานะ |
| `item_loans` | ใบยืมรายชิ้น ผู้ยืม ผู้รับผิดชอบ วันกำหนดคืน ผู้รับคืน และสภาพตอนคืน |
| `stock_movements` | ประวัติแบบเพิ่มแถวเท่านั้น ยอดก่อน ผลต่าง ยอดหลัง ผู้ทำ เวลา เหตุผลและรายการอ้างอิง |

## ความสอดคล้องของคลัง

เส้นทางธุรกรรมเรียก `record_movement` ซึ่งเปิด `BEGIN IMMEDIATE` ตรวจบทบาทและยอดล่าสุด แล้วบันทึกยอด สถานะ ใบยืม และประวัติพร้อมกัน SQLite ใช้ข้อจำกัดยอดไม่ติดลบ ดัชนีใบยืมเปิดหนึ่งใบต่อชิ้น และ trigger กันการแก้หรือลบประวัติ การส่งซ้ำด้วยรหัสและข้อมูลเดิมได้ผลอ้างอิงเดิม หากใช้รหัสเดิมกับข้อมูลใหม่ระบบปฏิเสธ ยอดพร้อมใช้ของเครื่องมือคำนวณจากชิ้นที่อยู่ในสถานะพร้อมใช้งาน

ฐานข้อมูลเก็บเวลา UTC หน้าจอและรายงานใช้เวลาไทย คำสั่งสำรองใช้ SQLite Backup API และไม่นำเซสชันติดไปกับสำเนา คู่มือ Windows ระบุการทดสอบกู้คืนลงฐานแยกก่อนเปิดใช้งานจริง
