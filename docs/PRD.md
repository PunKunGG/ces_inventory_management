# ขอบเขตผลิตภัณฑ์ CES Inventory MVP

โครงการใช้ CES Inventory Management System SRS v1.0 Draft และแบบที่ผู้ใช้ยืนยันสำหรับ MVP กลุ่มเป้าหมายคือเจ้าหน้าที่ห้องช่าง CES โรงพยาบาลกรุงเทพขอนแก่น ซึ่งต้องค้นทะเบียนและตำแหน่งได้ ทำธุรกรรมได้จากมือถือ และตรวจสอบยอดกับประวัติย้อนหลังได้ หน้าจอใช้ชื่อ CES Inventory คู่กับตราและชื่อโรงพยาบาลกรุงเทพขอนแก่น

- QR กลางเก็บ URL ทางเข้า ผู้ใช้ยืนยันตัวตนด้วยบัญชี CES และรหัสผ่าน
- Administrator ดูแลบัญชี หมวดหมู่ ตำแหน่ง ทะเบียน ปรับยอดและสถานะเครื่องมือ Technician รับเข้า เบิก ยืมและคืน Supervisor ทวนสอบประวัติและรายงาน ธุรกรรมมีผลทันทีในต้นแบบ
- อะไหล่และวัสดุสิ้นเปลืองหนึ่งรหัสมีหนึ่งจุดเก็บ เครื่องมือมีรหัสรายชิ้น ผู้เบิก ผู้ยืม และผู้รับผิดชอบเลือกจากบัญชี CES ผู้ทำรายการมาจากเซสชัน
- รายงานคงเหลือและใกล้หมดใช้ยอดปัจจุบัน รายงานรับเข้าและเบิกจ่ายมีตัวกรองช่วงวันที่ รายงานทั้งสี่ส่งออก CSV ได้ เกณฑ์หมดสต็อกคือยอดศูนย์ เกณฑ์ใกล้หมดคือยอดบวกที่ไม่เกินขั้นต่ำ
- การปิดทะเบียนอะไหล่ต้องมียอดศูนย์ การปิดทะเบียนเครื่องมือต้องเคลียร์ใบยืมค้าง ประวัติยังอ่านได้ผ่านหน้าประวัติและรายงานที่เกี่ยวข้อง
- ขอบเขตการส่งมอบจบที่ต้นแบบบน Windows และข้อมูลจำลอง ฟังก์ชัน QR รายชิ้น, RFID, AI, HIS/ERP และการเชื่อมใบงานซ่อมเต็มรูปแบบอยู่ระยะถัดไป MVP เก็บเลขใบงานเป็นข้อมูลอ้างอิงตอนเบิก
